# nonogram 数织谜题

终端里的 Nonogram（数织 / Picross）小玩具：生成点对称小谜题、行列逻辑求解器、ASCII 渲染。纯 Python 标准库，零依赖。

## 玩法

```
                2
       5  5  3  2  5
 2  2 ··········
    5 ··········
 3  1 ··········
    5 ··········
 2  2 ··········
```

根据行列数字线索还原黑白像素图。数字表示该行/列连续黑块的长度。

## 用法

```bash
python -m nonogram                    # 生成一道 5x5 谜题
python -m nonogram --size 10         # 10x10
python -m nonogram --seed 42         # 可复现
python -m nonogram --show-solution   # 同时打印答案
python -m nonogram --save p.txt      # 存为文本
python -m nonogram --solve p.txt     # 求解文件中的谜题
```

文本格式：第一行是尺寸，接着 n 行行线索、n 行列线索（空线索记为 `0`）。

## 实现

- 生成器：上下镜像的随机图案（保证有点内容，不会全空/全满）
- 求解器：行列"所有合法填充取交集"逻辑传播 + 猜测回溯
- 渲染：`██` 黑块 / `··` 未知 / 空格留白

## 真实验证记录

- 手工验算的 5x5 十字谜题：求解器输出与原图逐格一致
- 20 个种子（0–19）生成的 5x5：20/20 的解都满足线索；其中 18 个与原图完全一致，另 2 个（seed 10、14）是**天生多解**的谜题——求解器找到了另一个同样合法的解，原图本身也满足线索，不是求解器 bug
- 文本存取往返一致；矛盾线索正确返回"无解"
- 10x10 生成+求解正常（秒级）

## 已知局限（诚实版）

- 只做小棋盘（5/10）；回溯在大棋盘上会变慢
- **不保证唯一解**：随机图案约束不足时可能多解，生成器不做唯一性筛选
- 只有命令行界面，没有交互式填涂（看题+对答案模式）
- 终端需支持 Unicode 方块字符
